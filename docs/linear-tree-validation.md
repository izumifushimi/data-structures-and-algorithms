# 线性结构与树：代码审阅记录

审阅了两个知识库共 29 篇文档、136 个代码块，未修改 source-exports 原始导出。两篇无代码；其余 27 篇的修正及概念说明已写入 review-linear-tree.json，共 80 个修正块。代码块索引对应每篇 HTML body 的 pre/code 顺序，从 0 起。

使用 clang++ -std=c++17，在补齐同章类型及标准头文件的上下文中编译并执行了 17 组断言测试：顺序表、循环链串、矩阵、哈夫曼、逆波兰、线索树、线段树、堆、双亲树、左孩子右兄弟树、二叉树、课后习题片段、链队列、循环队列、广义表、循环单链表、双向链表。覆盖空结构、表满、非法索引、单字符编码、链串块大小边界、懒更新后的单点更新等情形。

完整“练习”程序另行编译执行，自带的顺序表合并、双向链表合并、单链表复制/删除、多项式加乘和相邻交换样例通过。验证用的 C++ 源码已整理至 tests/linear-tree/，不包含临时二进制。

并非全部 136 块都作为独立程序编译；其中有 API 用法语句和依赖前文类型的函数片段。JSON 的 notes 明确了有关依赖与输入前提。保留了原函数思路，没有将所有片段扩写为通用独立程序。

须注意：

- 课后题中使用 pre 的 ChainList 要求双向链表定义。
- paTree/lrbTree 的 create、递归/迭代 preOrder、普通/循环表 cl_search 是同签名的替代示例，不能同时定义。
- rcl_split 保留头插方式，结果内相对顺序逆转。
- left_bigger 统计左侧连续严格较大的元素数量。
- 二叉树括号形式为 (左 根 右)，标签限单字符，要求括号表达式合法。
- 表达式求值限定合法二元整数四则表达式，不支持一元负号或浮点字面量。
- 数值溢出、矩阵维度、数组容量与有效树下标仍依赖各节说明的输入范围。
